# 硬件-模型匹配矩阵（8000~50000 元价位段）

> BoxBench 附件 ｜ v1.0 ｜ 2026-11-11
> 用途：设备到手后先采集硬件指纹 → 自动分档 → 匹配可跑模型区间 → 生成测试清单（不支持的标"硬件不支持"，太浪费的标"不必要验证"）

## 1. 设备分档标准

按**可用于推理的内存**（统一内存取总量；独立加速卡取 min(系统内存, 卡显存)）分五档：

| 档位 | 推理内存 | 典型设备（参考价位） | 定位 |
|---|---|---|---|
| **D1 入门** | < 7GB | RK3588 8GB 板、Jetson Orin Nano 8GB（¥8000~12000） | 嵌入式，仅小模型 |
| **D2 主流** | 7~14GB | RK3588 16GB、Jetson Orin NX 16GB、Atlas 200I A2（¥12000~25000） | 轻量推理 |
| **D3 中档** | 14~28GB | 算能 BM1688 32GB、Orin NX 16GB 大内存版（¥20000~35000） | 中型模型 |
| **D4 高档** | 28~64GB | MTT E300K 类（30GB 统一内存，50TOPS）、Orin NX 32GB（¥30000~50000） | 35B 级主力 |
| **D5 旗舰** | ≥64GB | AGX Orin 64GB、Atlas 300I Duo 类（¥45000~50000+，贴预算上限） | 70B 级 |

> 判定以**可用于推理的内存**为准（加速卡显存优先，无卡取系统内存），GB 取整。档位边界考虑系统占用：如 32GB 统一内存实际可用约 30GB，判 D4；64GB 实际约 60GB+，判 D5。

> 价位为国内市场参考价（2026 年），实际以采购报价为准。档位判定以**内存为主**，NPU/GPU 算力（TOPS）作参考修正：算力 <10TOPS 时模型档位下调一档（如 D2 内存但 NPU 仅 6TOPS，按 D1 跑）。

| Qwen3.5-4B 级 Flash 类 | Q4 | 高速场景 |

### D3（16~32GB）— 中型

### D4（32~64GB）— 35B 级主力（本次预算甜点位）
| 模型 | 量化 | 用途 |
|---|---|---|
| **Qwen3.6-35B-A3B（W4A8）** | W4A8 | 基准主力（E300K 实测：加载131s，TTFT 0.40s，显存仅 4.0G/30G，4路并发无衰减） |
| Qwen3.8-27b-mtp（W4A8） | W4A8 | 备选（E300K 实测：显存 6.2G，TTFT 1.12s，各项通过） |

## 3. 跳过判定规则（写入测试清单生成）

对每个待测模型，按设备档位 D 和模型档位 M（按模型 dense 参数量/量化后体积折算）判定：

```
M ≤ D            → ✅ 测试（在区间内）
M = D + 1        → ⚠️ 边界尝试（内存刚好够时可试，标注"边界"）
M ≥ D + 2        → ⏭ 硬件不支持 — 需推理内存 {需求}，实际 {实际}（自动跳过）
M ≤ D - 2        → ◼ 不必要验证 — 模型档位远低于设备档位，浪费算力（自动跳过）
```

模型档位折算（int4/W4A8 量化后体积）：

| 模型档位 | 参数量 | 量化后体积(约) | 建议内存 |
|---|---|---|---|
| M1 | ≤4B | ≤3GB | ≥4GB |
| M2 | 7~9B | 4~6GB | ≥8GB |
| M3 | 14B / 30B-A3B MoE | 8~18GB | ≥16GB |
| M4 | 32~35B | 18~24GB | ≥24GB |
| M5 | 70B+ / 80B-A3B | 38~45GB | ≥48GB |

**示例**：
- D4 设备（E300K, 31GB）测 Qwen3.6-35B → M4 = D4 → ✅ 测试
- D4 设备测 Qwen3-1.7B → M1 ≤ D4-2 → ◼ 不必要验证（1.7B 放 5 万设备上跑纯属浪费）
- D2 设备（RK3588 16GB）测 Qwen3.6-35B → M4 ≥ D2+2 → ⏭ 硬件不支持 — 需 ≥24GB，实际 16GB
- D4 设备测 GLM-4.5-Air（M5 边缘）→ ⚠️ 边界尝试

## 4. 与测试流程的衔接

`boxbench.sh classify` 自动输出设备档位 + 推荐测试清单（含每档代表模型），Agent 据此生成最终测试清单，用户指定的模型不在区间内的按上述规则标注跳过原因，**报告中显示但不计入通过率**。
